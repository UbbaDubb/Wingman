# Wingman reports/

Generated by `python -m wingman.logging.report`, rerun anytime — every file
here is overwritten, nothing is hand-edited. Source: `logs/*.jsonl`.

FRAMING: every P&L figure across all four charts is UNREALIZED mark-to-market.
No position has been closed; every contract expires 2026-09-18, after the
hackathon. All x-axes show market hours only (13:30-20:00 UTC), with lines
broken (not connected) at day boundaries — no dead space for closed hours.

| File | What it shows |
